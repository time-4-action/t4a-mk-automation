Only mapped price lists are synced. A price list's code means nothing across companies — T4A 7 is "PP GOLD 2026" while CREAGLOBE 7 is "PP BRONZE 2026". Pairs are configured in the admin portal (Automation → Pricelists); this page shows what is configured and lets you run it. Always Preview (Dry Run) first.
